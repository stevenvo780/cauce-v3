# Inventario de estados de la consola V4

Inventario de lectura del código actual de `console/src/features/**`, contrastado con las rutas de `console/src/App.tsx` y sus componentes montados. La línea de aceptación correspondiente es `GOAL.md:192`. Se incluyen páginas y paneles con lectura, formulario o acción propia; los controles visuales reutilizables se recogen junto con la vista que los monta.

En «vacío», «sí» significa que el componente diferencia una lectura vacía de un fallo o de una fuente no disponible. «No aplica» identifica una pantalla sin colección de datos. Las rutas de las celdas son relativas a `console/src/features/`. En las celdas de prueba se cita un caso existente en el archivo indicado; no significa que ese caso se haya ejecutado durante este inventario.

## Huecos

- **Ajustes / autoridad de empresa — lista vacía sin texto.** Cuando no hay administradores ni personas elegibles, las listas quedan vacías y el selector conserva sólo «Elige persona»; no se explica el estado de ninguna colección. `console/src/features/config/CompanyAdminsPanel.tsx:35-47`.
- **Ajustes / autoridad de empresa — carga de personas sin indicación.** La lectura de candidatos deshabilita el selector, pero el panel sólo anuncia la carga de la autoridad de empresa. `console/src/features/config/CompanyAdminsPanel.tsx:9-11,31-47`.
- **Historial del contexto — carga de página siguiente sin texto.** Al pulsar «Ver más», el botón queda deshabilitado mientras se lee la página; no aparece un anuncio de carga junto a las entradas conservadas. `console/src/features/live/HistorialDeContexto.tsx:191-199,302-310,383-389`.
- **Oficina / campus — estado vacío sin siguiente acción.** La oficina anuncia «No lo sé: no hay ni un alias que mirar», pero no presenta una invitación visible para registrar agentes cuando el campus llega con cero vistas. `console/src/features/live/LiveFleetPage.tsx:171-175,241-265`.
- **Oficina / topología — error mostrado como ausencia de salas.** `LiveFleetPage` calcula las vistas desde `topology.data` y pasa el dato, no `topology.error`, a `OfficeWorkspace`; con fallo de topología el plano puede decir «Aún no hay salas». El veredicto sólo recibe `activity.error`. `console/src/features/live/LiveFleetPage.tsx:84-97,241-245`; `console/src/features/office/OfficeWorkspace.tsx:32-40,72-76`.
- **Mis cuotas / carga inicial de entornos y preferencias.** La página sólo anuncia carga de cuentas. Mientras `environments` siga sin snapshot, el panel de entornos no informa que está cargando y deja el formulario deshabilitado sin explicación. `console/src/features/accounts/MyQuotasPage.tsx:17-20,67-70`; `console/src/features/accounts/QuotaEnvironmentPanel.tsx:30-36,52-67`.
- **Señales y relays / carga inicial de relays.** Si llega primero la lectura de señales y `listOriginRelays()` sigue pendiente sin datos, la rama de lista vacía muestra «El servidor no devolvió ningún relay visible». Falta diferenciar esa espera de una respuesta vacía; sólo el encabezado refleja la carga agregada. `console/src/features/observability/ObservabilityPage.tsx:35-36,54,62,77-82`.
- **Backup del espacio / ausencia inicial.** Al abrir, sin operación previa, sólo aparece el botón «Crear backup del espacio»; el panel no declara si todavía no hay backup. No hay consulta de historial al montar. `console/src/features/live/SpaceBackupPanel.tsx:28-37,93-111`.
- **Chat / relectura fallida del roster.** El error de flota sólo se renderiza cuando `agents.length === 0`; con el último roster conservado, la vista sigue mostrando agentes sin avisar que falló la relectura. `console/src/features/messages/ChatLauncher.tsx:278-293`.
- **Colas / relectura fallida de entregas.** La pantalla corta a error sólo cuando no existe snapshot. Si falla el poll o la relectura con datos anteriores, se conservan las filas sin banner de error. `console/src/features/queues/QueuesPage.tsx:48-55,72-89`.
- **DLQ operativo / relectura fallida del primer snapshot.** El estado de error inicial requiere `!resource.data`; tras una lectura previa fallida no se comunica el snapshot desactualizado. `console/src/features/queues/OperationalDlqPanel.tsx:277-284`.
- **Señales, relays y auditoría / error de relectura con datos previos.** Las ramas de error de las lecturas principales se condicionan a no tener datos; con snapshot conservado no se anuncia que la última consulta falló. Para relays, el error también queda oculto si ya existía una lista. `console/src/features/observability/ObservabilityPage.tsx:49-50,77-82`; `console/src/features/audit/AuditPanel.tsx:120-121`.
